Ruta de la clase

La clase avanza desde una lectura simple de volumen hasta composiciones que mezclan varias bandas del espectro. Cada paso separa un concepto para mantener clara la lógica.

1. Señal

El audio cambia constantemente y necesita interacción de usuario para iniciar en navegador.

2. Análisis

Amplitud, FFT y waveform entregan datos de energía, distribución y movimiento.

3. Composición

Mapear datos a escala, color, rotación, líneas y capas construye una pieza visual intencional.

Teoría mínima para leer audio

Podemos observar el sonido por forma de onda en el tiempo y energía por bandas de frecuencia.

Amplitud

Expresa intensidad general y suele mapearse a escala, pulso, grosor, opacidad o zoom.

Frecuencia

Describe velocidad de vibración y se separa en graves, medios y agudos con comportamientos distintos.

FFT

Divide la señal en bins y cada bin da energía entre 0 y 255.

Waveform

fft.waveform() devuelve muestras entre -1 y 1 para líneas orgánicas.

Cómo procesarlo con p5.js

La mecánica se repite: cargar audio, iniciar por interacción, analizar y mapear a visuales.

let song;
let fft;
let amplitude;

function preload() {
  song = loadSound("/audio/ItsOnlyNatural.mp3");
}

function setup() {
  createCanvas(windowWidth, windowHeight);
  fft = new p5.FFT(0.85, 64);
  amplitude = new p5.Amplitude();
  fft.setInput(song);
  amplitude.setInput(song);
}

function draw() {
  const spectrum = fft.analyze();
  const waveform = fft.waveform();
  const level = amplitude.getLevel();
}
